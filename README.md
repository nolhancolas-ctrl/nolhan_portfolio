Nolhan — Creative Developer Portfolio
Thoughtful design. Fluid interactions. Digital experiences that feel alive.

This is my personal portfolio: a place to present selected work, explore interaction design and show how I approach the space between UI/UX design and front-end engineering.
Rather than treating a portfolio as a static gallery, I built it as a digital experience in its own right — with motion, visual depth and considered details throughout.

Highlights

Selected work — a dedicated project showcase with visual galleries and detailed presentation.
Motion-first interface — transitions, micro-interactions and scroll-aware elements built with Framer Motion.
Visual experimentation — 3D and shader-driven effects used to give the interface depth.
Smooth navigation — refined scrolling, responsive layouts and interactive media viewing.
Bilingual experience — content and interface in English and French.
Beyond the gallery — my process, services, pricing, FAQ and ways to get in touch or book a call.

Getting started

```bash
git clone https://github.com/nolhancolas-ctrl/nolhan_portfolio.git
cd nolhan_portfolio
npm install
npm run dev
```

Open http://localhost:3000.
The public URL can be configured using `NEXT_PUBLIC_SITE_URL`; otherwise, the site uses `https://nolhan-dev.com`.

Project structure

```text
app/           Next.js pages and layouts
components/    Layout, page sections and project UI
hooks/         Shared React hooks and language state
lib/           Site configuration, motion helpers and content
public/        Project imagery and assets
```

Design philosophy

I believe the best digital experiences are both useful and memorable. Every interaction should have a purpose; every visual detail should support the content. This portfolio is an ongoing exploration of that balance.
