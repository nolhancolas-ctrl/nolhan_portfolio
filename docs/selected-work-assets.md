# Selected Work — image slots

The website is ready for these files. Export each image at its **exact filename** below, place it under `public/`, and rebuild/redeploy the site. The homepage and `/work` discover the files automatically. Until an image is present, its card keeps a designed title treatment rather than a broken image.

Use real exports or screenshots from your own Figma projects. Keep each desktop capture wide (about 1600 × 1000 px, WebP, ideally below 500 KB). Show a meaningful viewport or detail, with no Figma interface or browser chrome. The website displays the complete image with `object-contain` and offers a zoomable view on the Work page.
